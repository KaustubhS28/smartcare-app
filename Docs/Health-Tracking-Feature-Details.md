# Health Tracking Feature - Technical Documentation

## Overview
The Health Tracking feature provides comprehensive health monitoring and goal management capabilities. Users can view their health overview, create and manage health goals, and track progress towards their wellness objectives.

**Base URL:** `/api/v1/healthtracking`  
**Authentication:** Required (JWT Token)  
**Role:** USER

---

## Endpoints

### 1. Get Health Tracking Overview

**Endpoint:** `GET /api/v1/healthtracking/overview`  
**Description:** Retrieves a comprehensive health overview including health score and progress metrics  
**Authentication:** Required

#### Request
- **Method:** GET
- **Headers:**
  - `Authorization: Bearer {jwt_token}` **(Mandatory)**
- **Body:** None

#### Response (200 OK)
```json
{
  "healthScore": 85,
  "activity": 75,
  "sleep": 80,
  "nutrition": 90,
  "vitals": 85,
  "goals": [
    {
      "id": 1,
      "goalType": "WEIGHT_LOSS",
      "description": "Lose 10 pounds in 3 months",
      "targetValue": 10,
      "currentValue": 3,
      "status": "IN_PROGRESS",
      "startDate": "2024-01-01",
      "endDate": "2024-04-01"
    }
  ]
}
```

#### Response Fields
- `healthScore`: Overall health score (0-100)
- `activity`: Activity progress percentage (0-100)
- `sleep`: Sleep quality progress percentage (0-100)
- `nutrition`: Nutrition progress percentage (0-100)
- `vitals`: Vitals monitoring progress percentage (0-100)
- `goals`: Array of current health goals

#### Error Responses
```json
// 401 Unauthorized
{
  "timestamp": "2024-01-15T10:30:00",
  "status": 401,
  "error": "Unauthorized",
  "message": "Authentication required",
  "path": "/api/v1/healthtracking/overview"
}

// 500 Internal Server Error
{
  "timestamp": "2024-01-15T10:30:00",
  "status": 500,
  "error": "Internal Server Error",
  "message": "Unable to retrieve health overview",
  "path": "/api/v1/healthtracking/overview"
}
```

### 3. Add New Health Goal

**Endpoint:** `POST /api/v1/healthtracking/goals`  
**Description:** Creates a new health goal for the authenticated user  
**Authentication:** Required

#### Request
- **Method:** POST
- **Headers:**
  - `Authorization: Bearer {jwt_token}` **(Mandatory)**
  - `Content-Type: application/json` **(Mandatory)**

#### Request Body
```json
{
  "goalType": "WEIGHT_LOSS",
  "description": "Lose 10 pounds in 3 months",
  "targetValue": 10,
  "currentValue": 0,
  "status": "IN_PROGRESS",
  "startDate": "2024-01-01",
  "endDate": "2024-04-01"
}
```

#### Request Fields
- `goalType`: Type of health goal **(Mandatory)**
- `description`: Goal description (optional)
- `targetValue`: Target value to achieve (optional, default: 0)
- `currentValue`: Current progress value (optional, default: 0)
- `status`: Goal status (optional, default: "IN_PROGRESS")
- `startDate`: Goal start date (optional, default: current date)
- `endDate`: Goal target end date (optional)

#### Excluded Fields (Set by System)
- `id`: Auto-generated by system

#### Response (200 OK)
```json
{
  "id": 3,
  "goalType": "WEIGHT_LOSS",
  "description": "Lose 10 pounds in 3 months",
  "targetValue": 10,
  "currentValue": 0,
  "status": "IN_PROGRESS",

}
```

## UI Integration Guidelines

### 1. Health Overview Dashboard
- **Display health metrics as progress bars or circular indicators**
- **Use color coding:** Green (80-100%), Yellow (60-79%), Red (below 60%)
- **Show goals in a summary card format with progress indicators**
- **Implement auto-refresh every 30 seconds for real-time updates**

### 2. Goal Management Interface
- **Provide goal type dropdown with predefined options**
- **Implement date pickers for start and end dates**
- **Show progress visualization (progress bars, charts)**
- **Enable inline editing for quick updates**

### 3. Form Validation
```javascript
const validateGoalForm = (formData) => {
  const errors = {};
  
  if (!formData.goalType?.trim()) {
    errors.goalType = 'Goal type is required';
  }
  
  if (formData.targetValue < 0) {
    errors.targetValue = 'Target value must be positive';
  }
  
  if (formData.endDate && formData.startDate && new Date(formData.endDate) <= new Date(formData.startDate)) {
    errors.endDate = 'End date must be after start date';
  }
  
  return errors;
};
```

### 4. State Management
```javascript
const healthTrackingState = {
  overview: {
    healthScore: 0,
    metrics: {},
    goals: [],
    loading: false,
    error: null
  },
  goals: {
    list: [],
    loading: false,
    error: null,
    filters: {
      status: 'ALL',
      goalType: 'ALL'
    }
  }
};
```

### 5. Error Handling
- **Display user-friendly error messages for each error type**
- **Implement retry mechanisms for network failures**
- **Show loading states during API calls**
- **Provide fallback content when data is unavailable**

### 6. Security Considerations
- **Always include JWT token in request headers**
- **Validate user permissions before showing edit/delete options**
- **Implement proper session timeout handling**
- **Sanitize user input before sending to API**

### 7. Performance Optimization
- **Cache overview data for 5 minutes to reduce API calls**
- **Implement lazy loading for goal lists**
- **Use pagination for large goal datasets**
- **Debounce search and filter operations**

### 8. Accessibility
- **Provide screen reader support for progress indicators**
- **Use semantic HTML for goal status and metrics**
- **Implement keyboard navigation for goal management**
- **Add ARIA labels for interactive elements**

## Common Goal Types
- `WEIGHT_LOSS`: Weight reduction goals
- `WEIGHT_GAIN`: Weight increase goals
- `EXERCISE`: Physical activity goals
- `NUTRITION`: Dietary and nutrition goals
- `SLEEP`: Sleep quality and duration goals
- `HYDRATION`: Water intake goals
- `MEDITATION`: Mindfulness and meditation goals
- `STEPS`: Daily step count goals

## Goal Status Types
- `IN_PROGRESS`: Currently active goal
- `COMPLETED`: Successfully achieved goal
- `PAUSED`: Temporarily suspended goal
- `CANCELLED`: Abandoned goal
